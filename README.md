# inventory-control-api

this is a symple inventory control api

## Run

```dev
pnpm run dev
```

```schema
pnpm run schema
```

## Endpoints

#### product

GET /product

POST /product

GET /product/:id

PUT /product/:id

DELETE /product/:id

#### trash

GET /trash

GET /trash/:id

PATCH /trash/:id/restore

#### movement

GET /movement

POST /movement
